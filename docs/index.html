产品边界

拾光是家庭回忆整理和日常陪伴工具，不提供医疗诊断，不替代医生或专业照护建议，也不承诺治疗、延缓病程或产生确定疗效。

隐私优先

家庭资料主要通过用户自己的 iCloud / CloudKit 私有数据库在设备间同步。只有在用户主动使用相应智能整理或声音功能时，完成该功能所需的部分数据才会提交给服务端或受托服务提供商处理。拾光不展示第三方广告，不出售个人信息，也不将数据用于跨 App 追踪。

关于照片、照片位置、声音、家庭线索、标识符、保存与删除方式，请阅读完整的隐私政策。
